# Fundamentos de Python

Este repositorio reúne una serie de ejercicios, prácticas y retos de programación en Python, organizados por temas para facilitar el aprendizaje progresivo de los conceptos básicos y intermedios del lenguaje.

La idea principal es servir como material de estudio y referencia para quienes inician en Python y desean fortalecer sus habilidades mediante ejemplos prácticos.

## ¿Qué incluye este proyecto?

El contenido está dividido en tres áreas principales:

- Fundamentos básicos de Python
- Control de flujo y funciones
- Estructuras de datos y ejercicios prácticos

## Estructura del repositorio

- [Fundamentos_Python](Fundamentos_Python/): ejercicios iniciales de introducción a Python.
- [Fundamentos_Python_Control_Fun](Fundamentos_Python_Control_Fun/): práctica con condicionales, funciones e iteraciones.
- [Python_Estructuras_Datos](Python_Estructuras_Datos/): ejercicios sobre listas, tuplas, diccionarios, conjuntos y comprehensions.

## Contenido por módulos

### 1. Fundamentos_Python
Incluye ejercicios introductorios para familiarizarse con la sintaxis de Python, variables, entrada/salida y conceptos básicos de programación.

### 2. Fundamentos_Python_Control_Fun
Contiene ejemplos relacionados con:
- condicionales
- funciones
- estructuras iterativas

### 3. Python_Estructuras_Datos
Aquí se encuentran ejercicios y retos sobre:
- listas
- tuplas
- diccionarios
- conjuntos
- comprehensions

## Cómo usar este repositorio

1. Clona el repositorio en tu computadora.
2. Abre la carpeta correspondiente al tema que quieras practicar.
3. Ejecuta los archivos .py con Python desde la terminal.

Ejemplo:

```bash
python nombre_del_archivo.py
```

## Objetivo

Este proyecto busca ayudar a comprender de forma práctica los fundamentos de Python mediante ejercicios organizados y fáciles de seguir.

## Requisitos

- Python 3 instalado en tu sistema.
- Un editor de texto o IDE como Visual Studio Code.

## Nota

Este repositorio está pensado como material de estudio y práctica, por lo que puede ir creciendo con nuevos ejercicios y retos a medida que se avanza en el aprendizaje.
